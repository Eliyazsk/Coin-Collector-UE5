# 🎮 Coin Collector – Unreal Engine 5

## 📌 About the Project
Coin Collector is a 3D platformer game developed using Unreal Engine 5. The player can move, run, jump, and collect coins while exploring the game environment.

This project is part of my journey to learn game development and build practical skills using Unreal Engine 5.

## ✨ Features
- 🏃 Player movement and running
- 🦘 Jump mechanics
- 🪙 Coin collection
- 🌍 3D game environment
- 🎮 Interactive gameplay mechanics

## 🛠️ Technologies Used
- Unreal Engine 5
- Blueprints
- 3D Game Development

## 🎯 Project Objective
To learn and implement fundamental game development concepts, including character movement, jumping, and coin collection in a 3D environment.
